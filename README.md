# PZDREAM - Tienda de Tecnología

Plataforma web de comercio electrónico para la venta de productos tecnológicos, desarrollada como proyecto fullstack. Incluye módulos de catálogo, carrito de compras, autenticación de usuarios, panel de administración y sistema de consultas comunitarias.

## Descripción

**PZDREAM** es una tienda online especializada en hardware, periféricos y equipos de computación. El proyecto simula un e-commerce funcional con las siguientes características principales:

- **Catálogo de productos** con tarjetas interactivas y filtrado por categorías.
- **Página de detalle** para cada producto con especificaciones técnicas.
- **Carrito de compras** dinámico (sin persistencia en localStorage).
- **Sistema de autenticación** para usuarios (registro e inicio de sesión).
- **Panel de administración** para gestionar productos (CRUD).
- **Sección de contacto** con formulario de consultas y publicaciones comunitarias.

##  Tecnologías Utilizadas

| Tecnología | Propósito |
|------------|-----------|
| **HTML5** | Estructura de las páginas |
| **CSS3** | Estilos personalizados y diseño responsive |
| **JavaScript (ES6)** | Lógica del frontend (carrito, autenticación, CRUD) |
| **Bootstrap 5.3.8** | Framework CSS para componentes y grid |
| **Font Awesome 6.5** | Iconografía |
